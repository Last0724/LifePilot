# LifePilot

An AI-powered personal productivity planner.

## Overview

LifePilot uses AI to understand users' goals, work habits, and schedules, then generates personalized weekly and daily plans.

## Core Features

- Structured AI consultation
- Adaptive follow-up questions
- Personalized productivity analysis
- Weekly and daily scheduling
- Interactive task management
- Deliberately frustrating UX mechanisms

## Technology Stack

- Python
- Streamlit
- DeepSeek API
- Git and GitHub

## Running Locally

Install dependencies:

    pip install -r requirements.txt

Run the application:

    streamlit run app.py

## API Configuration

Store API credentials in Streamlit secrets.
Never commit API keys or private credentials.

## AI Disclosure

This project uses DeepSeek API for AI-powered consultation and productivity analysis.
